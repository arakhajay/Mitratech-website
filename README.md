# MitraTech - Enterprise Agency Website

> **Transforming Ideas into Powerful Digital Solutions**

MitraTech is a production-ready, enterprise-grade digital agency web application built with **Next.js 15**, **React 19**, **TypeScript**, and **Tailwind CSS**.

---

## 🚀 Features

- **Next.js 15 App Router**: Server-Side Rendering (SSR) & Static Site Generation (SSG) for 32 prerendered pages.
- **Glassmorphic UI**: Ultra-modern dark mode visual aesthetics with HSL-tailored color tokens (`#2563EB`, `#7C3AED`, `#06B6D4`, `#0F172A`).
- **Full Page Suite**:
  - **Home**: 100vh Hero with floating glow badges, Client Marquee, Interactive Stats Counters, Portfolio Showcase, 7-Step Process Timeline, Tech Stack Grid, Testimonials Carousel, FAQ Accordion, and CTA Banner.
  - **About**: Company Story, Mission/Vision, Core Values, 5-Year History Timeline, and Leadership Team.
  - **Services Hub & 6 Detail Pages**: Website Design, Website Development, Web App Development, Social Media Marketing, Creative Graphic Design, Google Ads.
  - **Portfolio & Case Studies**: Filterable masonry grid with case studies detailing Challenge, Technical Solution, and Quantified Results.
  - **Pricing**: Starter, Pro Growth, and Enterprise Custom packages with interactive monthly/annual billing toggle & feature comparison matrix.
  - **Blog**: Searchable articles on Next.js performance, UI/UX trends, and Google Ads optimization.
  - **Careers**: Culture perks, active job roles, and application form.
  - **Contact**: Interactive form with React Hook Form + Zod validation, direct contact cards, map placeholder, and instant WhatsApp chat.
- **SEO & Schema**: Dynamic Next.js Metadata API, JSON-LD Schemas (Organization, LocalBusiness, Service, FAQPage), `sitemap.xml`, and `robots.txt`.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 15.5
- **Library**: React 19, TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide Icons
- **Form Handling**: React Hook Form + Zod

---

## 💻 Local Development Setup

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run Development Server**:
   ```bash
   npm run dev
   ```

3. **Build & Production Server**:
   ```bash
   npm run build
   npm run start
   ```
